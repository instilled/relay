# Flows, PR 2: state between steps — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A step leaves values and files for the steps after it — `rl flow state`, `$RELAY_OUT`,
`$RELAY_WORK` in `runs/<firing>/` — and they reach later prompts, `if:`, `group:` and commands
(`$RELAY_IN/<step>.out`, `$RELAY_V_<step>_<key>`); a firing's folder goes with its runs at
retention.

**Architecture:** What may be kept is decided in a new pure module, `rl-flow/src/state.rs`
(keys, names, caps, `$RELAY_OUT` lines, variable names). Values live in a new ledger table beside
the steps (`step_values`, in `firings.rs`); files live on disk in `runs/<firing>/`, laid out by a
new `rl-daemon/src/flows/work.rs`. One reader of "what a step left" — `flows/facts.rs`, moved out of
`engine.rs` and taught values — answers placeholders, `if:`, `group:`, `rl flow state get` and a
step's environment alike. `rl flow state` is four `flow.state.*` methods carried out by
`flows/state.rs`, which finds the step from the run asking. Retention (`gc.rs`) removes the folders
of firings it knows have ended, and nothing else under `runs/`.

**Tech Stack:** Rust 2024 workspace (`Cargo.toml` at the repo root, crates under `code/`), tokio,
rusqlite (numbered SQL migrations), serde, clap, jiff. Daemon integration tests use
`code/rl-daemon/tests/common` (`Harness`, `Conn`, `approve`); a test that needs the real `rl` finds
it beside `rld` (`rl_bin()` in `tests/flow_on.rs`).

**Spec:** `docs/specs/2026-10-07-flows.md` — read "State between steps" whole, and "The PRs" item 2.
This plan is PR 2 of four ("State"); PR 1 (`docs/plans/2026-10-07-flows-1.md`, merged as #151)
built the folder, loading, approval, the engine, `ask` steps and `{x.out}` in prompts. Build on it;
do not rebuild it.

## Global Constraints

## Review Focus

- **Hand-made things under `runs/`.** prod-logs keeps `runs/seen` beside its firings; a flow may

- **A probe's `$RELAY_OUT` as shells write it.** `\r\n` line ends, no final newline, a blank line,

- **A lost step picked up again.** What its first run appended to `$RELAY_OUT` before it was lost

```rust
//! What a step leaves for the steps after it, checked before it is kept: a value's key and size,
//! a file's name and size, the `key=value` lines a step appends to `$RELAY_OUT`, and the variable
//! a command reads a value from. The daemon keeps what passes; what does not is refused, saying why.

/// The most a value may be, in bytes.
pub const VALUE_MAX: usize = 4 << 10;
/// The most a file written through `rl flow state write` may be, in bytes.
pub const FILE_MAX: usize = 10 << 20;
/// The most a step's `$RELAY_OUT` may be, in bytes: it is read whole at the step's end.
pub const OUT_FILE_MAX: usize = 1 << 20;
/// What Relay itself says of a step, so no value may be called it.
pub const RESERVED: &[&str] = &["out", "choice", "note"];

/// A value's key: `[a-z][a-z0-9_]*`, and none of [`RESERVED`]. It is a placeholder's
/// (`{probe.signature}`) and part of a variable's name (`$RELAY_V_probe_signature`), and nothing
/// else fits both.
pub fn key(k: &str) -> Result<(), String> {
    let mut chars = k.chars();
    let word = chars.next().is_some_and(|c| c.is_ascii_lowercase())
        && chars.all(|c| c.is_ascii_lowercase() || c.is_ascii_digit() || c == '_');
    if !word {
        return Err(format!("`{k}` is not a value's key: a-z, 0-9 and _, from a letter"));
    }
    if RESERVED.contains(&k) {
        return Err(format!("`{k}` is Relay's to say of a step, not a value's key"));
    }
    Ok(())
}

/// A value as it may be kept: its key good, and 4 KB at most.
pub fn value(k: &str, v: &str) -> Result<(), String> {
    key(k)?;
    if v.len() > VALUE_MAX {
        return Err(format!(
            "`{k}` is {} bytes; a value is 4 KB at most — write a file instead",
            v.len()
        ));
    }
    Ok(())
}

/// A file's name in a firing's folder: one name — no `/`, no `..`, not hidden (a name from a dot
/// is Relay's own), 255 bytes at most — and never a step's out (`probe.out` is what probe printed).
/// `steps` are the flow's step names.
pub fn file_name(name: &str, steps: &[&str]) -> Result<(), String> {
    let plain = !name.is_empty()
        && name.len() <= 255
        && !name.starts_with('.')
        && !name.contains(['/', '\0'])
        && !name.contains("..");
    if !plain {
        return Err(format!(
            "`{name}` is not a file's name here: one name, no / or .., not starting with a dot"
        ));
    }
    if let Some(step) = out_of(name, steps) {
        return Err(format!("`{name}` is what {step} printed, not a file to write"));
    }
    Ok(())
}

/// A file a step writes through `rl flow state write`: its name as [`file_name`] has it, and
/// 10 MB at most.
pub fn file(name: &str, len: usize, steps: &[&str]) -> Result<(), String> {
    file_name(name, steps)?;
    if len > FILE_MAX {
        return Err(format!("`{name}` is {len} bytes; a file is 10 MB at most"));
    }
    Ok(())
}

/// The step whose out `name` is: `probe.out` is probe's, when probe is one of `steps`.
pub fn out_of<'a>(name: &str, steps: &[&'a str]) -> Option<&'a str> {
    let step = name.strip_suffix(".out")?;
    steps.iter().copied().find(|s| *s == step)
}

/// The values in what a step appended to `$RELAY_OUT`: a `key=value` a line, the value all after
/// the first `=`, `\r\n` read as `\n`, blank lines skipped, a key said twice its last. Anything
/// else is refused, at its line: a step that meant to say something is not let go on without it.
pub fn out_lines(text: &str) -> Result<Vec<(String, String)>, String> {
    if text.len() > OUT_FILE_MAX {
        return Err(format!("$RELAY_OUT is {} bytes; 1 MB at most", text.len()));
    }
    let mut kept: Vec<(String, String)> = Vec::new();
    for (i, line) in text.lines().enumerate() {
        if line.trim().is_empty() {
            continue;
        }
        let Some((k, v)) = line.split_once('=') else {
            return Err(format!("$RELAY_OUT line {}: `{line}` is not key=value", i + 1));
        };
        value(k, v).map_err(|e| format!("$RELAY_OUT line {}: {e}", i + 1))?;
        kept.retain(|(had, _)| had != k);
        kept.push((k.to_string(), v.to_string()));
    }
    Ok(kept)
}

/// The variable a command reads an earlier step's value from: `RELAY_V_<step>_<key>`, a `-` in
/// the step's name made `_` so a shell can name it (`new-errors` → `RELAY_V_new_errors_found`).
pub fn env_name(step: &str, key: &str) -> String {
    format!("RELAY_V_{}_{key}", step.replace('-', "_"))
}
```

```rust
/// Refuses a placeholder in what a command line is made of: what a step left could otherwise
/// become shell. `step` is the step it is in; `label` says where (`b`, or `b.ok` for an option).
fn command(step: &str, label: &str, action: &Action, flow: &Flow, said: &mut Vec<String>) {
    let words: Vec<&String> = match &action.run {
        Some(Task::Shell(line)) => vec![line],
        Some(Task::Argv(argv)) => argv.iter().collect(),
        Some(Task::Agent { args, .. }) => args.iter().collect(),
        None => vec![],
    };
    for r in words.iter().flat_map(|w| template::refs(w)) {
        if r.head == "event" || flow.names.contains(r.head.as_str()) {
            said.push(format!(
                "`{label}`: `{{{}.{}}}` cannot go into a command — read `{}`",
                r.head,
                r.rest,
                instead(step, &r)
            ));
        }
    }
}

/// The variable a command reads instead: the event's, what a step printed under `$RELAY_IN`, an
/// ask's own answer in its option, and any other value as `$RELAY_V_<step>_<key>`.
fn instead(step: &str, r: &Ref) -> String {
    match (r.head.as_str(), r.rest.as_str()) {
        ("event", "summary") => "$RELAY_EVENT_SUMMARY".to_string(),
        ("event", "kind") => "$RELAY_EVENT_KIND".to_string(),
        ("event", "run") => "$RELAY_EVENT_RUN".to_string(),
        ("event", _) => "$RELAY_EVENT".to_string(),
        (head, "out") => format!("$RELAY_IN/{head}.out"),
        (head, "choice") if head == step => "$RELAY_CHOICE".to_string(),
        (head, "note") if head == step => "$RELAY_NOTE".to_string(),
        (head, key) => format!("${}", state::env_name(head, key)),
    }
}
```

```rust
/// Keeps values a step set, each over any it set before under the same key.
pub fn set_values(conn: &Connection, firing: &str, step: &str, values: &[(String, String)]) -> Result<()> {
    let tx = conn.unchecked_transaction()?;
    for (key, value) in values {
        tx.execute(
            "INSERT INTO step_values (firing, step, key, value) VALUES (?1, ?2, ?3, ?4) \
             ON CONFLICT (firing, step, key) DO UPDATE SET value = excluded.value",
            params![firing, step, key, value],
        )?;
    }
    tx.commit()?;
    Ok(())
}

/// One value a step set.
pub fn value(conn: &Connection, firing: &str, step: &str, key: &str) -> Result<Option<String>> {
    Ok(conn
        .query_row(
            "SELECT value FROM step_values WHERE firing = ?1 AND step = ?2 AND key = ?3",
            params![firing, step, key],
            |r| r.get(0),
        )
        .optional()?)
}

/// Every value a step set, by key.
pub fn values(conn: &Connection, firing: &str, step: &str) -> Result<BTreeMap<String, String>> {
    let mut stmt = conn.prepare("SELECT key, value FROM step_values WHERE firing = ?1 AND step = ?2")?;
    let rows = stmt.query_map(params![firing, step], |r| Ok((r.get(0)?, r.get(1)?)))?;
    Ok(rows.collect::<std::result::Result<_, _>>()?)
}
```

```rust
/// How much of a step's output is its `out`: the last of it.
pub(super) const OUT_MAX: usize = 64 << 10;

pub(super) struct Facts<'a> {
    conn: &'a Connection,
    firing: &'a str,
    steps: &'a [StepState],
    event: Option<BTreeMap<String, String>>,
}

impl<'a> Facts<'a> {
    pub(super) fn new(conn: &'a Connection, firing: &'a Firing, event: Option<&(Event, Option<Run>)>) -> Self {
        let event = event.map(|(e, run)| vars(e, run.as_ref()));
        Self {
            conn,
            firing: &firing.id,
            steps: &firing.steps,
            event,
        }
    }

    /// What `step` printed: the last 64 KB of its run, ANSI stripped and trimmed.
    pub(super) fn out(&self, step: &str) -> Option<String> {
        self.get(&Ref {
            head: step.to_string(),
            rest: "out".to_string(),
        })
    }
}

impl Lookup for Facts<'_> {
    fn get(&self, r: &Ref) -> Option<String> {
        if r.head == "event" {
            return self.event.as_ref()?.get(&r.rest).cloned();
        }
        let s = self.steps.iter().find(|s| s.name == r.head)?;
        let found = match r.rest.as_str() {
            "out" => {
                let run = s.run.as_deref()?;
                session_io::tail(self.conn, run, OUT_MAX).map(|b| Some(rl_detect::ansi::strip(&b).trim().to_string()))
            }
            "choice" | "note" => decisions::get(self.conn, s.decision.as_deref()?).map(|d| {
                let d = d?;
                match r.rest.as_str() {
                    "choice" => (!d.chosen.is_empty()).then(|| d.chosen.join(", ")),
                    _ => d.note,
                }
            }),
            key => firings::value(self.conn, self.firing, &s.name, key),
        };
        found.unwrap_or_else(|e| {
            warn!(step = s.name, error = %format!("{e:#}"), "reading what a step left");
            None
        })
    }
}
```

```rust
fn write(home: &Home, name: &str, files: &[(&str, &str)]) {
    let dir = home.flow_dir(name);
    std::fs::create_dir_all(&dir).unwrap();
    for (f, text) in files {

/// A daemon on a fresh home with `flow.md` written for `name`; `None` when `rl-session` is not built.
async fn start(tmp: &Path, name: &str, flow_md: &str) -> Option<(Harness, Conn)> {
    let home = Home::at(tmp.join("home"));
    write(&home, name, &[("flow.md", flow_md)]);
    let h = Harness::on(home)?;
    let c = Conn::open(&h.home).await;
    Some((h, c))
}

/// Polls `flow.firings` every 50 ms for 10 s until the newest firing is as `done` says.
async fn wait_firing(c: &mut Conn, flow: &str, done: impl Fn(&Firing) -> bool) -> Firing {
    let deadline = Instant::now() + Duration::from_secs(10);
    loop {
        let firings: Vec<Firing> = c.ok("flow.firings", json!({ "flow": flow })).await;
        if let Some(f) = firings.into_iter().next() {
            if done(&f) {
                return f;
            }
            assert!(Instant::now() < deadline, "the firing never got there: {f:?}");
        } else {
            assert!(Instant::now() < deadline, "`{flow}` never fired");
        }
        tokio::time::sleep(Duration::from_millis(50)).await;
    }
}

fn ended(f: &Firing) -> bool {
```

```rust
//! Under `.relay/<step>/`, apart from them, what Relay hands a step — `in/<step>.out` for each
//! step it comes after, `$RELAY_IN` — and what the step hands back: `out`, `$RELAY_OUT`, its
//! `key=value` lines read when it ends. A name from a dot is never a step's file
//! (`rl_flow::state::file_name`), so the two never meet.

use super::engine::def_of;

/// Relay's own corner of a firing's folder.
const OWN: &str = ".relay";

/// Where one step of one firing finds and leaves things.
pub(super) struct Work {
    /// `$RELAY_WORK`: the firing's folder.
    pub(super) dir: PathBuf,
    /// `$RELAY_IN`: what the steps before it printed, `<step>.out` each.
    pub(super) input: PathBuf,
    /// `$RELAY_OUT`: `key=value` lines the step appends.
    pub(super) out: PathBuf,
}

impl Work {
    pub(super) fn of(home: &Home, flow: &str, firing: &str, step: &str) -> Self {
        let dir = home.firing_dir(flow, firing);
        let own = dir.join(OWN).join(step);
        Self {
            input: own.join("in"),
            out: own.join("out"),
            dir,
        }
    }

    /// Made ready for the step to start: its folders there, what each step before it printed
    /// written under `$RELAY_IN`, and `$RELAY_OUT` there to append to. What the step appended
    /// before — a lost run's, picked up again — is kept.
    pub(super) fn prepare(&self, outs: &[(String, String)]) -> Result<()> {
        std::fs::create_dir_all(&self.input).with_context(|| format!("making {}", self.input.display()))?;
        for (step, out) in outs {
            write_atomic(&self.input.join(format!("{step}.out")), out.as_bytes())?;
        }
        std::fs::OpenOptions::new()
            .create(true)
            .append(true)
            .open(&self.out)
            .with_context(|| format!("making {}", self.out.display()))?;
        Ok(())
    }

    /// What the step appended to `$RELAY_OUT`, whole; `None` when there is no such file.
    /// Refused, saying why, past 1 MB or when it is not UTF-8.
    pub(super) fn appended(&self) -> Result<Option<String>, String> {
        let f = match std::fs::File::open(&self.out) {
            Ok(f) => f,
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => return Ok(None),
            Err(e) => return Err(format!("$RELAY_OUT could not be read: {e}")),
        };
        let mut bytes = Vec::new();
        f.take(OUT_FILE_MAX as u64 + 1)
            .read_to_end(&mut bytes)
            .map_err(|e| format!("$RELAY_OUT could not be read: {e}"))?;
        if bytes.len() > OUT_FILE_MAX {
            return Err("$RELAY_OUT is over 1 MB".to_string());
        }
        String::from_utf8(bytes)
            .map(Some)
            .map_err(|_| "$RELAY_OUT is not UTF-8".to_string())
    }
}

/// `bytes` at `path` all at once: written beside it under a dot name, then renamed over it, so a
/// reader sees the old file or the new, never part of one.
pub(super) fn write_atomic(path: &Path, bytes: &[u8]) -> Result<()> {
    static NEXT: AtomicU64 = AtomicU64::new(0);
    let dir = path.parent().context("a file with no folder")?;
    let name = path.file_name().context("a file with no name")?.to_string_lossy();
    let n = NEXT.fetch_add(1, Ordering::Relaxed);
    let tmp = dir.join(format!(".{name}.{}.{n}.tmp", std::process::id()));
    let written = std::fs::File::create(&tmp)
        .and_then(|mut f| f.write_all(bytes).and_then(|()| f.sync_all()))
        .and_then(|()| std::fs::rename(&tmp, path));
    if written.is_err() {
        let _ = std::fs::remove_file(&tmp);
    }
    written.with_context(|| format!("writing {}", path.display()))
}

impl Flows {
    /// A step's run ended well: what it appended to `$RELAY_OUT` becomes its values, before
    /// anything after it is decided. What cannot be kept is said in `flow.refused` and the step
    /// fails — a step that meant to say something does not let the rest go on without it. Only a
    /// step still running is read, so an end seen twice is read once.
    pub(super) async fn kept(&self, firing: &str, h: Happened) -> Happened {
        let Happened::Ended { step, ok: true } = &h else {
            return h;
        };
        let step = step.clone();
        let (id, s) = (firing.to_string(), step.clone());
        let found = self
            .ledger
            .call(move |c| {
                let running = firings::steps(c, &id)?.get(&s) == Some(&StepStatus::Running);
                if !running {
                    return Ok(None);
                }
                def_of(c, &id)
            })
            .await;
        let def = match found {
            Ok(Some(def)) => def,
            Ok(None) => return h,
            Err(e) => {
                warn!(firing, step, error = %format!("{e:#}"), "reading a step's $RELAY_OUT");
                return h;
            }
        };
        let work = Work::of(&self.home, &def.name, firing, &step);
        let why = match work.appended().and_then(|t| t.as_deref().map(out_lines).transpose()) {
            Ok(None) => return h,
            Ok(Some(values)) if values.is_empty() => return h,
            Ok(Some(values)) => {
                let (id, s) = (firing.to_string(), step.clone());
                match self.ledger.call(move |c| firings::set_values(c, &id, &s, &values)).await {
                    Ok(()) => return h,
                    Err(e) => format!("{e:#}"),
                }
            }
            Err(why) => why,
        };
        warn!(flow = def.name, firing, step, reason = why, "a step's $RELAY_OUT was not kept");
        let data = json!({ "flow": def.name, "firing": firing, "step": step, "reason": why });
        let summary = format!("flow `{}` step `{step}`: {why}", def.name);
        self.say(&def, event_kind::FLOW_REFUSED, summary, data).await;
        Happened::Ended { step, ok: false }
    }
}
```

```rust
//! through `rld`. The step is the run asking (`$RELAY_RUN`), while it runs — any other run, or

/// The step asking: the definition its firing runs on, the firing, the step's name.
struct Caller {
    def: FlowDef,
    firing: String,
    step: String,
}

impl Caller {
    fn steps(&self) -> Vec<&str> {
        self.def.steps.iter().map(|s| s.name.as_str()).collect()
    }

    fn work(&self, home: &Home) -> Work {
        Work::of(home, &self.def.name, &self.firing, &self.step)
    }

/// The step `run` is, while it runs; `None` for any other run, or one over.
fn caller(c: &Connection, run: &str) -> Result<Option<Caller>> {
    let Some((firing, step)) = firings::by_run(c, run)? else {
        return Ok(None);
    };
    if runs::get(c, run)?.is_none_or(|r| r.state.is_terminal()) {
        return Ok(None);
    }
    Ok(def_of(c, &firing)?.map(|def| Caller { def, firing, step }))
}

impl Flows {
    async fn caller(&self, run: &str) -> Result<Caller> {
        let run = run.to_string();
        match self.ledger.call(move |c| caller(c, &run)).await? {
            Some(who) => Ok(who),
            None => Err(Refusal(NOT_IN_A_STEP.to_string()).into()),
        }
    }

    /// `rl flow state set k=v…`: values of the asking step, each over any it set before.
    pub(crate) async fn state_set(&self, run: &str, values: Vec<(String, String)>) -> Result<()> {
        let who = self.caller(run).await?;
        for (k, v) in &values {
            state::value(k, v).map_err(Refusal)?;
        }
        self.ledger
            .call(move |c| firings::set_values(c, &who.firing, &who.step, &values))
            .await
    }

    /// `rl flow state get probe.signature`: what a step of this firing left — a value, its out,
    /// an ask's choice or note; a bare key is the asking step's own. `None`: not set.
    pub(crate) async fn state_get(&self, run: &str, name: &str) -> Result<Option<String>> {
        let who = self.caller(run).await?;
        let r = match name.split_once('.') {
            Some((head, rest)) => Ref {
                head: head.to_string(),
                rest: rest.to_string(),
            },
            None => Ref {
                head: who.step.clone(),
                rest: name.to_string(),
            },
        };
        if !who.steps().contains(&r.head.as_str()) {
            return Err(Refusal(format!("`{}` is no step of `{}`", r.head, who.def.name)).into());
        }
        self.ledger
            .call(move |c| {
                let f = firings::get(c, &who.firing)?.context("the firing")?;
                Ok(Facts::new(c, &f, None).get(&r))
            })
            .await
    }

    /// `rl flow state write <name>`: a file in the firing's folder, for the steps after it,
    /// written whole or not at all.
    pub(crate) async fn state_write(&self, run: &str, name: &str, bytes: Vec<u8>) -> Result<()> {
        let who = self.caller(run).await?;
        state::file(name, bytes.len(), &who.steps()).map_err(Refusal)?;
        let path = who.work(&self.home).dir.join(name);
        tokio::task::spawn_blocking(move || {
            std::fs::create_dir_all(path.parent().context("a firing's folder")?)?;
            write_atomic(&path, &bytes)
        })
        .await?
    }

    /// `rl flow state read <name>`: a file in the firing's folder, or what a step printed
    /// (`probe.out`).
    pub(crate) async fn state_read(&self, run: &str, name: &str) -> Result<Vec<u8>> {
        let who = self.caller(run).await?;
        if let Some(step) = state::out_of(name, &who.steps()).map(String::from) {
            let firing = who.firing.clone();
            let out = self
                .ledger
                .call(move |c| {
                    let f = firings::get(c, &firing)?.context("the firing")?;
                    Ok(Facts::new(c, &f, None).out(&step))
                })
                .await?;
            return Ok(out.unwrap_or_default().into_bytes());
        }
        state::file_name(name, &who.steps()).map_err(Refusal)?;
        let path = who.work(&self.home).dir.join(name);
        let name = name.to_string();
        tokio::task::spawn_blocking(move || read_capped(&path, &name)).await?
    }
}

/// A file of the firing's, 10 MB at most: one bigger is the step's to read from `$RELAY_WORK`.
fn read_capped(path: &Path, name: &str) -> Result<Vec<u8>> {
    let f = match std::fs::File::open(path) {
        Ok(f) => f,
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => {
            return Err(Refusal(format!("no `{name}` in this firing")).into());
        }
        Err(e) => return Err(e).with_context(|| format!("reading {}", path.display())),
    };
    let mut bytes = Vec::new();
    f.take(state::FILE_MAX as u64 + 1).read_to_end(&mut bytes)?;
    if bytes.len() > state::FILE_MAX {
        return Err(Refusal(format!("`{name}` is over 10 MB: read it from $RELAY_WORK")).into());
    }
    Ok(bytes)
}
```

```rust
//! `rl flow state set|get|write|read`: what a step leaves for the steps after it, and reads of
//! what theirs left. Only inside a step, and only through `rld`, which finds the step from
//! `$RELAY_RUN` — so one allow rule, `Bash(rl flow state:*)`, gives an agent its firing's state
//! and nothing else.

use crate::daemon;

use clap::Subcommand;
use rl_core::Home;

#[derive(Subcommand)]
pub enum StateCmd {
    /// Set values for the steps after this one: `rl flow state set signature=abc found=3`.
    Set {
        #[arg(required = true, value_name = "KEY=VALUE")]
        values: Vec<String>,
    },
    /// Print what a step left: `probe.signature`, `review.choice`, `probe.out`, or this step's own `key`.
    Get { name: String },
    /// Write stdin to a file in the firing's folder, for the steps after this one: `rl flow state write report.md < x`.
    Write { name: String },
    /// Print a file from the firing's folder, or what a step printed (`probe.out`).
    Read { name: String },
}

/// The run of the step this is called in, from what every step starts with; none outside one.
fn here() -> Result<String> {
    let set = |k: &str| std::env::var(k).ok().filter(|v| !v.is_empty());
    match (set("RELAY_RUN"), set("RELAY_FIRING"), set("RELAY_STEP")) {
        (Some(run), Some(_), Some(_)) => Ok(run),
        _ => bail!("not in a flow step"),
    }
}

pub async fn state(home: &Home, cmd: StateCmd, json: bool) -> Result<()> {
    let run = here()?;
    // Inside a step rld is running; nothing is said of it, so a step's out stays its own.
    let mut rpc = daemon::ensure(home, false).await?;
    match cmd {
        StateCmd::Set { values } => {
            let values = values
                .iter()
                .map(|kv| {
                    kv.split_once('=')
                        .map(|(k, v)| (k.to_string(), v.to_string()))
                        .with_context(|| format!("`{kv}` is not key=value"))
                })
                .collect::<Result<Vec<_>>>()?;
            rpc.call::<FlowStateSet>(StateValues { run, values }).await?;
        }
        StateCmd::Get { name } => {
            let value = rpc.call::<FlowStateGet>(StateName { run, name: name.clone() }).await?;
            if json {
                println!("{}", serde_json::json!({ "value": value }));
                return Ok(());
            }
            match value {
                Some(v) => println!("{v}"),
                None => bail!("`{name}` is not set"),
            }
        }
        StateCmd::Write { name } => {
            let mut bytes = Vec::new();
            std::io::stdin().take(FILE_MAX as u64 + 1).read_to_end(&mut bytes)?;
            if bytes.len() > FILE_MAX {
                bail!("`{name}` is over 10 MB: a file is 10 MB at most");
            }
            rpc.call::<FlowStateWrite>(StateFile { run, name, bytes }).await?;
        }
        StateCmd::Read { name } => {
            let bytes = rpc.call::<FlowStateRead>(StateName { run, name }).await?;
            std::io::stdout().write_all(&bytes)?;
        }
    }
    Ok(())
}
```

```rust
/// The folders of firings that ended before `before` — `runs/<firing>/` in each flow's folder,
/// all their steps left — gone with their runs' journals, unless `dry_run`. Only a folder named
/// for a firing of that flow the ledger knows has ended goes: anything else under `runs/` — a
/// file or a folder the flow keeps there itself, a firing still open — stays. How many went, and
/// their bytes.
async fn firing_folders(home: &Home, ledger: &Ledger, before: Timestamp, dry_run: bool) -> Result<(usize, u64)> {
    let mut seen: Vec<(String, Vec<String>)> = Vec::new();
    if let Ok(flows) = std::fs::read_dir(home.flows_dir()) {
        for flow in flows.flatten() {
            let name = flow.file_name().to_string_lossy().into_owned();
            if !valid_name(&name) {
                continue;
            }
            let Ok(entries) = std::fs::read_dir(flow.path().join("runs")) else {
                continue;
            };
            // A link is not followed: only a folder that is one.
            let ids = entries
                .flatten()
                .filter(|e| e.file_type().is_ok_and(|t| t.is_dir()))
                .map(|e| e.file_name().to_string_lossy().into_owned())
                .collect();
            seen.push((name, ids));
        }
    }
    let gone = ledger
        .call(move |c| {
            seen.into_iter()
                .map(|(flow, ids)| {
                    let ended = firings::ended_before(c, &flow, &ids, before)?;
                    Ok((flow, ended))
                })
                .collect::<Result<Vec<_>>>()
        })
        .await?;
    let (mut count, mut bytes) = (0usize, 0u64);
    for (flow, ids) in gone {
        for id in ids {
            let dir = home.firing_dir(&flow, &id);
            bytes += size_of(&dir);
            count += 1;
            if !dry_run && let Err(e) = std::fs::remove_dir_all(&dir) {
                warn!(flow, firing = id, error = %e, "gc: a firing's folder not removed");
            }
        }
    }
    Ok((count, bytes))
}

/// The bytes of the files under `dir`; a link is not followed.
fn size_of(dir: &Path) -> u64 {
    let Ok(entries) = std::fs::read_dir(dir) else { return 0 };
    entries
        .flatten()
        .map(|e| match e.file_type() {
            Ok(t) if t.is_dir() => size_of(&e.path()),
            _ => e.metadata().map(|m| m.len()).unwrap_or(0),
        })
        .sum()
}
```
