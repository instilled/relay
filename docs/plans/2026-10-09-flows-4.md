# Flows, PR 4: writing it — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A flow is written through `rl` and the panel, never by hand-copying: `rl flow new <name>`
and `/flow new` write one from plain words (an assistant drafts `flow.md`, you see it, enter writes
it and says yes), from a template Relay ships (`--from prod-logs`, `--from morning-brief`, their
few blanks filled), or from the bare template in `$EDITOR`; the context pack teaches an assistant
what a flow is, built from the code; and `rl flow test` / `/flow test` say what would fire and
which steps would run, starting nothing.

**Architecture:** A new flow goes through the edit path PR 1 built (`finish_edit`, its yes by
hash): `rl-cli/src/flow.rs`'s editing moves to `flow/edit.rs`, an `Editing` learns whether what was
written is the person's (`yours`: a filled template or a draft, kept and said yes to even saved
unchanged) or the bare template (dropped when left as it was), and `flow/new.rs` writes a fresh
folder and hands it to that path. Templates are folders under `rl-cli/templates/` compiled in
(`flow/templates.rs`) with `{{key}}` blanks filled at `new`; what is particular to a person reaches
a template's scripts through their step's `env:`, so no one's ids are in one. The interpreter
answers `kind: run` or `kind: flow` + a whole `flow.md` (`interpret.rs`); the pack's flow section is
`context/flows.rs`, its keys held to `FlowSpec`/`StepSpec` by a test, its `if:` forms, variables and
event names read from `rl-flow`. `flow.test` is decided purely in `rl-flow/src/preview.rs` (which
steps would run, what each does) and carried out in `rl-daemon/src/flows/preview.rs` (held, next
times, an event's verdict, where each step runs); `flow/tested.rs` says it for the CLI and the
panel. The panel's draft is a new mode drawn in the pane (`tui/new_flow.rs`); `tui/mod.rs` gets the
wiring only.

**Tech Stack:** Rust 2024 workspace (`Cargo.toml` at the repo root, crates under `code/`), tokio,
rusqlite, serde (+ serde_norway for YAML), clap, ratatui, jiff. Daemon integration tests use
`code/rl-daemon/tests/common` (`Harness`, `Conn`, `approve`); CLI tests drive the built `rl`
against a throwaway `RELAY_HOME` (`code/rl-cli/tests/{flow,interpret}.rs`); panel tests run a real
`rld` over a fresh home (`tui/mod.rs` `tests::panel*`). The only agent anywhere is
`code/fixtures/fake-agent`.

**Spec:** `docs/specs/2026-10-07-flows.md` — read "Loading and approval" (the yes by writing
through `rl`), "Where you see it" → **Commands** and **Drafting**, "State between steps" (what the
pack teaches), and "The PRs" item 4: "Writing it. `rl flow new` and `/flow new` with words, the
context pack, `rl flow test`, and prod-logs and morning-brief as templates (`rl flow new prod-logs
--from prod-logs`)." PR 1 (#151) built `rl flow edit` / `/flow edit` (`start_edit`, `finish_edit`,
`drop_template`), approval by hash and loading; PR 2 (#153) `rl flow state`, `$RELAY_WORK`,
`$RELAY_IN`, `$RELAY_OUT`; PR 3 (#154, #155) the outcome a firing came to and `catch_up: top`. The
interpreter (`rl interpret`, the panel's ask line, `assistants.interpret`) and the context pack
(`rl context`) predate flows. Build on all of them; do not rebuild them.

## Review Focus

- **A blank that would break what it is written into.** `--set project=my "prod"`, `space=`,
  `org={probe.out}`, a key the template has no blank for, a blank left out: refused before a file
  is written, saying which blank and what it takes — never a half-written folder, never a value
  that ends a YAML string or becomes a placeholder. Tests: Task 1
  `a_blank_is_checked_before_anything_is_filled`; Task 2
  `flow_new_writes_a_template_filled_and_says_yes` (nothing under `flows/logs` after each refusal).
- **A name that is already a flow.** `rl flow new prod-logs` twice, `/flow new nightly` on a flow
  that exists, a draft whose name is taken: refused by name, pointing at `edit`, and the flow
  there byte for byte as it was. Tests: Task 2 (second `new` refused, `flow.md` unchanged); Task 7
  `flow_new_fills_a_template_and_its_save_is_the_yes`.
- **However the editor ends.** A filled template or a draft saved unchanged is the person's and
  gets its yes; the bare template left as it was is not kept; an editor that fails (`EDITOR=false`)
  leaves nothing of a new flow behind and approves nothing; a template filled into a folder that
  does not load (its `in` not a project Relay knows) is said, at its line, with `rl add`. Tests:
  Task 2 `flow_new_writes_a_template_filled_and_says_yes`.
- **An answer that is not what was asked.** Asked for a flow, the assistant answers a run; a flow
  with no `---` after `kind: flow`; a prompt echoed back above the answer; a draft that would not
  load (an unknown `after`) or names no flow: said by name, nothing written — the panel's enter on
  such a draft writes nothing and the draft stays up. Tests: Task 4
  `a_flow_is_read_from_its_kind_line_to_the_end`, `words_become_a_flow_and_go_writes_it`; Task 7
  `a_drafted_flow_is_shown_then_written_with_its_yes`.
- **A test that would do something.** `rl flow test` on an approved flow with a `when` due, with an
  `--event` that would fire it: no firing, no run, no question afterwards; on a flow that did not
  load it says why at its line; an event id that does not exist is said. Tests: Task 5
  `a_test_says_when_and_which_steps_and_starts_nothing`,
  `an_event_says_whether_it_fires_the_flow_and_what_its_steps_do`, `what_cannot_be_tested_is_said`.

```sh
#!/bin/sh
# Errors the GCP project $GCP_PROJECT logged since the last check (runs/last; the first time, the
# last 24 hours) that were never reported before, one line per kind: count, where, message with
# numbers and ids blanked so repeats group. Prints nothing when there is nothing new.
#
# Kinds already reported are kept in runs/seen: runs/ is outside the flow's hash, so remembering
# them asks no new yes. Delete a line there to hear about that kind again. Cluster noise
# (kube-system, gke-*) is left out; LOG_FILTER in the probe's env replaces the whole filter.
set -eu
: "${GCP_PROJECT:?set GCP_PROJECT in the probe step's env}"
runs="${RELAY_FLOW_DIR:-$(dirname "$0")}/runs"
mkdir -p "$runs"
seen="$runs/seen"
last="$runs/last"
touch "$seen"
now=$(date -u +%Y-%m-%dT%H:%M:%SZ)
since=$(cat "$last" 2>/dev/null ||
  date -u -d "24 hours ago" +%Y-%m-%dT%H:%M:%SZ 2>/dev/null || date -u -v-24H +%Y-%m-%dT%H:%M:%SZ)
filter=${LOG_FILTER:-'severity>=ERROR AND NOT resource.labels.namespace_name=("kube-system" OR "gke-managed-system" OR "gmp-system")'}
# Read whole first: a read that fails fails the step, and runs/last stays where it was.
logs=$(gcloud logging read "($filter) AND timestamp>=\"$since\"" \
  --project "$GCP_PROJECT" --limit 2000 --format json)
printf '%s\n' "$logs" |
  jq -r '.[] | [
      ((.resource.labels.namespace_name // .resource.type // "") + "/" + (.resource.labels.container_name // .resource.labels.service_name // (.resource.labels.pod_name // "" | sub("-[a-z0-9]+-[a-z0-9]+$"; "")))),
      ((.textPayload // .jsonPayload.message // .jsonPayload.msg // (.jsonPayload | tostring) // "") | tostring | gsub("\\s+"; " ") | .[0:300])
    ] | @tsv' |
  sed -E 's/[0-9a-f]{8}-[0-9a-f-]{27}/<id>/g; s/[0-9]+/N/g' |
  sort | uniq -c | sort -rn |
  {
    # Forty kinds at most; the rest stay unseen, and come next time.
    n=0
    while IFS= read -r line; do
      [ "$n" -lt 40 ] || break
      kind=$(printf '%s\n' "$line" | sed -E 's/^ *[0-9]+ //')
      grep -qxF -- "$kind" "$seen" && continue
      printf '%s\n' "$kind" >> "$seen"
      printf '%s\n' "$line"
      n=$((n + 1))
    done
  }
printf '%s\n' "$now" > "$last"
```

`code/rl-cli/templates/morning-brief/notion.py`:

```python
#!/usr/bin/env python3
"""Notion pages edited in the brief's days (yesterday; on a Monday, Friday through Sunday), as the
account ntn is signed in to: who, page, url.

Notion's API does not name users for a personal token, so names come from the people fields
(assignee, attendees, …) of the pages it returns; an editor named nowhere stays an id. The
signed-in person is "(me)".
"""
import datetime as dt, json, subprocess, sys

def api(path, body):
    out = subprocess.run(["ntn", "api", path, "-d", json.dumps(body)], capture_output=True, text=True, stdin=subprocess.DEVNULL)
    if out.returncode:
        sys.exit(out.stderr.strip() or "ntn failed")
    return json.loads(out.stdout)

me = subprocess.run(["ntn", "whoami"], capture_output=True, text=True, check=True, stdin=subprocess.DEVNULL).stdout.split("\t")
me_id = me[6] if len(me) > 6 else ""

today = dt.datetime.now().astimezone().replace(hour=0, minute=0, second=0, microsecond=0)
start, end = today - dt.timedelta(days=3 if today.isoweekday() == 1 else 1), today

def title(p):
    for v in (p.get("properties") or {}).values():
        if v.get("type") == "title":
            return "".join(t["plain_text"] for t in v["title"])
    return "".join(t["plain_text"] for t in p.get("title", []))

pages, names, cursor = [], {}, None
while True:
    body = {"sort": {"timestamp": "last_edited_time", "direction": "descending"},
            "filter": {"property": "object", "value": "page"}, "page_size": 100}
    if cursor:
        body["start_cursor"] = cursor
    r = api("/v1/search", body)
    done = False
    for p in r["results"]:
        for v in (p.get("properties") or {}).values():
            for u in v.get("people", []) if v.get("type") == "people" else []:
                if u.get("name"):
                    names[u["id"]] = u["name"]
        at = dt.datetime.fromisoformat(p["last_edited_time"].replace("Z", "+00:00"))
        if at < start:
            done = True
            break
        if at < end:
            pages.append(p)
    if done or not r.get("has_more"):
        break
    cursor = r["next_cursor"]
```

```rust
//! — `flow.md` and its scripts, under `rl-cli/templates/<template>/`, compiled in — with named

use super::new::NewFile;
use std::collections::BTreeMap;

/// What a template leaves for the person: `{{key}}` wherever it goes.
pub struct Blank {
    pub key: &'static str,
    /// What it is, as a question would ask it.
    pub what: &'static str,
    /// What one looks like.
    pub like: &'static str,

/// The template by its name.
pub fn find(name: &str) -> Result<&'static Template, String> {
    ALL.iter()
        .find(|t| t.name == name)
        .ok_or_else(|| format!("`{name}` is not a template: {}", names()))
}

/// Every template's name, in the order shipped.
pub fn names() -> String {
    ALL.iter().map(|t| t.name).collect::<Vec<_>>().join(", ")
}

/// The blanks given as `key=value` words, and `in`, when the template has one and it is not
/// given, the folder `here` (as a path is shown: `~/…`).
pub fn given_in<S: AsRef<str>>(t: &Template, words: &[S], here: &str) -> Result<BTreeMap<String, String>, String> {
    let mut given = BTreeMap::new();
    for w in words {
        let w = w.as_ref();
        let Some((k, v)) = w.split_once('=') else {
            return Err(format!("`{w}` is not key=value"));
        };
        given.insert(k.trim().to_string(), v.trim().to_string());
    }
    if t.blanks.iter().any(|b| b.key == IN) {
        given.entry(IN.to_string()).or_insert_with(|| here.to_string());
    }
    Ok(given)
}

/// The blanks not given yet.
pub fn missing<'a>(t: &'a Template, given: &BTreeMap<String, String>) -> Vec<&'a Blank> {
    t.blanks.iter().filter(|b| !given.contains_key(b.key)).collect()
}

/// What a template still needs, each as it would be given: `prefix` is `--set ` on the command
/// line and nothing in the panel.
pub fn needs(t: &Template, missing: &[&Blank], prefix: &str) -> String {
    let each: Vec<String> = missing
        .iter()
        .map(|b| format!("{prefix}{}=… ({}, like {})", b.key, b.what, b.like))
        .collect();
    format!("{} needs {}", t.name, each.join(" · "))
}

/// A blank's value: something, and nothing that would end the YAML string it goes into (`"`,
/// `\`), make a placeholder (`{`, `}`) or break a line.
pub fn value(key: &str, v: &str) -> Result<(), String> {
    let bad = v.trim().is_empty() || v.chars().any(|c| c.is_control() || matches!(c, '"' | '\\' | '{' | '}'));
    if bad {
        return Err(format!("`{key}`: a blank takes a word or a path, without \" \\ {{ or }}"));
    }
    Ok(())
}

/// The template's files, every blank filled from `given` — each blank given, each value good,
/// and nothing given that is not a blank — or why not, before anything is filled.
pub fn fill(t: &Template, given: &BTreeMap<String, String>) -> Result<Vec<NewFile>, String> {
    if let Some(k) = given.keys().find(|k| !t.blanks.iter().any(|b| b.key == k.as_str())) {
        let keys: Vec<&str> = t.blanks.iter().map(|b| b.key).collect();
        return Err(format!("`{k}` is not a blank of {}: {}", t.name, keys.join(", ")));
    }
    let gone = missing(t, given);
    if !gone.is_empty() {
        return Err(needs(t, &gone, ""));
    }
    for (k, v) in given {
        value(k, v)?;
    }
    Ok(t.files
        .iter()
        .map(|f| {
            let mut text = f.text.to_string();
            for (k, v) in given {
                text = text.replace(&format!("{{{{{k}}}}}"), v);
            }
            NewFile {
                path: PathBuf::from(f.path),
                bytes: text.into_bytes(),
                exec: f.exec,
            }
        })
        .collect())
}
```

```rust
/// nothing before, `flow.md` is untouched and the folder is as written. Back from the editor
/// (`unseen` false) only the bare template goes — a filled template or a draft is the person's;

pub fn drop_new(home: &Home, e: &Editing, unseen: bool) -> Result<bool> {
    let dir = home.flow_dir(&e.name);
    let untouched = std::fs::read(&e.file).is_ok_and(|now| now == e.was);
    if !(e.fresh && (unseen || !e.yours) && untouched && folder_files(&dir)? == e.before) {
        return Ok(false);

        std::fs::remove_file(dir.join(p))?;
    }
    // Not empty: something not the edit's is there, and stays.
    let _ = std::fs::remove_dir(&dir);
    Ok(true)
}
```

```rust
pub fn check_name(home: &Home, name: &str) -> Result<()> {

    }

/// A new flow's folder written — `files`, `flow.md` among them, none there before — and its
/// `flow.md` ready for an editor. `yours`: what was written is the person's (a template they
/// filled, a draft they asked for), kept and said yes to even saved unchanged; else it is the
/// bare template, kept only once changed.
pub fn start_new(home: &Home, name: &str, files: Vec<NewFile>, yours: bool) -> Result<Editing> {
    check_name(home, name)?;
    if !files.iter().any(|f| f.path == Path::new("flow.md")) {
        bail!("a new flow needs a flow.md");
    }
    let dir = home.flow_dir(name);
    if let Some(f) = files.iter().find(|f| dir.join(&f.path).exists()) {
        bail!("{} is there already: a new flow writes only what is not", display_path(&dir.join(&f.path)));
    }
    let fresh = folder_files(&dir)?.is_empty();
    std::fs::create_dir_all(&dir).with_context(|| format!("creating {}", dir.display()))?;
    for f in &files {
        write(&dir.join(&f.path), &f.bytes, f.exec)?;
    }
    let file = dir.join("flow.md");
    Ok(Editing {
        name: name.to_string(),
        before: folder_files(&dir)?,
        was: std::fs::read(&file)?,
        file,
        fresh,
        yours,
    })
}

/// A file written, and made executable when a step runs it.
fn write(path: &Path, bytes: &[u8], exec: bool) -> Result<()> {
    std::fs::write(path, bytes).with_context(|| format!("writing {}", path.display()))?;
    #[cfg(unix)]
    if exec {
        use std::os::unix::fs::PermissionsExt;
        std::fs::set_permissions(path, std::fs::Permissions::from_mode(0o755))?;
    }
    Ok(())
}

/// `rl flow new`: the bare template, or a template filled — written to a new folder, opened in
/// `$EDITOR` unless `--go`, and said yes to as an edit is, when it loads.
pub async fn new(home: &Home, a: NewArgs, json: bool) -> Result<()> {
    let folder = match &a.folder {
        Some(f) => f.clone(),
        None => std::env::current_dir()?,
    };
    let folder = std::fs::canonicalize(&folder).unwrap_or(folder);
    check_name(home, &a.name)?;
    let (files, yours) = match &a.from {
        Some(t) => (template_files(t, &a.set, &folder)?, true),
        None if a.go => bail!("--go writes a template as it is filled; the bare template needs $EDITOR"),
        None => (vec![NewFile::flow_md(TEMPLATE)], false),
    };
    let editing = start_new(home, &a.name, files, yours)?;
    if !a.go
        && let Err(e) = crate::env::open_in_editor(&editing.file, 1)
    {
        if let Err(left) = drop_new(home, &editing, true) {
            bail!("{e:#}; and what was written is left: {left:#}");

        return Err(e);
    }
    let mut rpc = daemon::ensure(home, !json).await?;
    let (edited, reloaded) = finish_edit(&mut rpc, home, editing).await?;
    super::told(&edited, &reloaded, &a.name, json)
}

/// A template's files, its blanks from `--set`, `in` from the folder, and — on a terminal — the
/// rest asked for; off one, what is missing is said.
fn template_files(name: &str, set: &[String], folder: &Path) -> Result<Vec<NewFile>> {
    let t = templates::find(name).map_err(anyhow::Error::msg)?;
    let mut given = templates::given_in(t, set, &display_path(folder)).map_err(anyhow::Error::msg)?;
    let missing = templates::missing(t, &given);
    if !missing.is_empty() && !std::io::stdin().is_terminal() {
        bail!("{}", templates::needs(t, &missing, "--set "));
    }
    for b in missing {
        eprint!("{} (like {}): ", b.what, b.like);
        let mut line = String::new();
        std::io::stdin().read_line(&mut line)?;
        given.insert(b.key.to_string(), line.trim().to_string());
    }
    templates::fill(t, &given).map_err(anyhow::Error::msg)
}
```

/// A flow's `flow.md` as drafted, and the name the assistant gave it, if it gave one.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct FlowDraft {
    pub name: Option<String>,
    pub text: String,
}

/// What the assistant answered.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Answer {
    Run(Draft),
    Flow(FlowDraft),
}

/// The answer in what the assistant said. A flow is the first `kind: flow` at the start of a
/// line — the pack's own shapes are indented, so an echo of it is never one — then its `name:`,
/// then its `flow.md` from a `---` line to the end, a closing fence dropped. Anything else is a
/// run ([`parse`]).
pub fn answer(raw: &str) -> Result<Answer> {
    let lines: Vec<&str> = raw.lines().collect();
    let is_flow = |l: &&str| l.starts_with("kind:") && strip_comment(l["kind:".len()..].trim()) == "flow";
    let Some(at) = lines.iter().position(is_flow) else {
        return parse(raw).map(Answer::Run);
    };
    let Some(dash) = lines[at..].iter().position(|l| l.trim_end() == "---").map(|i| at + i) else {
        bail!("kind: flow, then its flow.md from a `---` line: there is none");
    };
    let name = lines[at + 1..dash]
        .iter()
        .find_map(|l| l.strip_prefix("name:"))
        .map(|n| unquote(&strip_comment(n.trim())))
        .filter(|n| !n.is_empty());
    let mut body: Vec<&str> = lines[dash..].to_vec();
    while body.last().is_some_and(|l| l.trim().is_empty() || l.trim_start().starts_with("```")) {
        body.pop();
    }
    Ok(Answer::Flow(FlowDraft {
        name,
        text: format!("{}\n", body.join("\n")),
    }))
}

```rust
/// Asks the interpreter: the pack for `folder` and what is wanted, then the words. What comes
/// back, read, with the run that said it. A whole flow takes longer to write than a run: three
/// minutes rather than the assistant's one.
pub async fn ask(home: &Home, folder: &Path, words: &str, want: &Want) -> Result<(Answer, AssistantOutput)> {
    let mut rpc = Client::connect(home).await?;
    let here: Here = context::gather(&mut rpc, folder).await?;
    let pack = context::render(context::help(), &here, want);
    let prompt = context::ask(&pack, words);
    let title = format!("interpret: {}", words.chars().take(48).collect::<String>());
    let timeout = matches!(want, Want::Flow { .. }).then(|| "3m".to_string());
    let out = rpc
        .call::<AssistantRun>(AssistantParams {
            job: "interpret".into(),
            prompt,
            cwd: folder.to_path_buf(),
            title,
            timeout,
        })
        .await?;
    if out.timed_out {
        bail!("{} took too long and was stopped (run {})", out.agent, out.run);
    }
    let said = answer(&out.output)
        .with_context(|| format!("{} answered (run {}):\n{}", out.agent, out.run, out.output.trim()))?;
    Ok((said, out))
}

    let mut rpc = Client::connect(home).await?;
    crate::flow::finish_edit(&mut rpc, home, editing).await
}
```

```rust
//! What a firing started now would do, told before it starts: which steps would run, which only
//! if a step before them leaves something, which not — and what each does, in a line. Nothing
//! runs; `flow.test` hands in the event, if one was named.

use crate::def::{Does, FlowDef, Step};
use crate::plan;
use crate::template::{Lookup, Ref};
use rl_proto::action::{Action, Task};
use rl_proto::flow::Runs;
use std::collections::BTreeMap;

/// Each step, in the order written, and whether it would run. A step's `if:` on a step before it
/// cannot be known before that step runs: it is said as a condition, with those of the steps it
/// waits on. One on the event is decided when an event is given (`event` looks up `{event.…}`).
pub fn steps(def: &FlowDef, event: Option<&dyn Lookup>) -> Vec<(String, Runs)> {
    let graph: Vec<(String, Vec<String>)> = def.steps.iter().map(|s| (s.name.clone(), s.after.clone())).collect();
    // A loaded flow has no cycle; were one there, the order written is as good as any.
    let order = plan::order(&graph).unwrap_or_else(|_| graph.iter().map(|(n, _)| n.clone()).collect());
    let mut said: BTreeMap<String, Runs> = BTreeMap::new();
    for name in &order {
        if let Some(step) = def.steps.iter().find(|s| &s.name == name) {
            let runs = runs(step, &said, event);
            said.insert(name.clone(), runs);
        }
    }
    def.steps
        .iter()
        .map(|s| (s.name.clone(), said.remove(&s.name).unwrap_or(Runs::Yes)))
        .collect()
}

/// One step, given what was said of those before it.
fn runs(step: &Step, before: &BTreeMap<String, Runs>, event: Option<&dyn Lookup>) -> Runs {
    let mut conds: Vec<String> = Vec::new();
    let mut add = |c: String| {
        if !conds.contains(&c) {
            conds.push(c);
        }
    };
    for a in &step.after {
        match before.get(a) {
            Some(Runs::No(_)) => return Runs::No(format!("after {a}, which would not run")),
            Some(Runs::If(cs)) => cs.iter().cloned().for_each(&mut add),
            _ => {}
        }
    }
    if let Some(c) = &step.if_ {
        match (c.subject().head.as_str(), event) {
            ("event", Some(e)) if !c.holds(e) => return Runs::No(format!("if {c}: not for this event")),
            ("event", Some(_)) => {}
            _ => add(c.to_string()),
        }
    }
    if conds.is_empty() { Runs::Yes } else { Runs::If(conds) }
}

/// What a step does, in a line: its command, its agent and the first line of its prompt, or its
/// question with its options, the default and when.
pub fn does(step: &Step) -> String {
    match &step.does {
        Does::Run(a) => line(&action_words(a)),
        Does::Ask(ask) => {
            let options: Vec<String> = ask
                .options
                .iter()
                .map(|(o, a)| if a.is_empty() { o.clone() } else { format!("{o} ({})", who(a)) })
                .collect();
            let mut s = format!("asks {} · {}", line(&ask.text), options.join(", "));
            if let Some(d) = &ask.default {
                s.push_str(&format!(" · {d}"));
                if let Some(e) = &ask.expires {
                    s.push_str(&format!(" in {e}"));
                }
            }
            s
        }
    }
}

fn action_words(a: &Action) -> String {
    match &a.run {
        Some(Task::Agent { agent, prompt, .. }) => {
            format!("{agent} · {}", prompt.as_deref().unwrap_or("(its prompt file)"))
        }
        Some(t) => t.label(),
        None => "nothing".to_string(),
    }
}

/// Who an option's action is: its agent, or its command.
fn who(a: &Action) -> String {
    match &a.run {
        Some(Task::Agent { agent, .. }) => agent.clone(),
        _ => line(&a.label()),
    }
}

/// The first line, 60 characters at most, a cut one ending in `…`.
fn line(s: &str) -> String {
    let first = s.lines().next().unwrap_or("").trim_end();
    match first.char_indices().nth(59) {
        Some((cut, _)) if first.chars().count() > 60 => format!("{}…", &first[..cut]),
        _ => first.to_string(),
    }
}
```

```rust
    /// What firing `name` would do now, and with `event`, what that event would make of it.
    pub(crate) async fn test(&self, name: &str, event: Option<i64>) -> Result<Tested> {
        self.reload().await?;
        if self.not_loaded().iter().any(|n| n.flow == name) {
            return Err(Untested::Missing.into());
        }
        let n = name.to_string();
        let (flow, last) = self
            .ledger
            .call(move |c| Ok((flows::get(c, &n)?, firings::latest(c, &n)?)))
            .await?;
        let Some(f) = flow.filter(|f| f.removed_at.is_none()) else {
            return Err(Untested::Missing.into());
        };

        let now = Timestamp::now();

            None => None,
            Some(id) => {
                let e = self
                    .ledger
                    .call(move |c| events::get(c, id))
                    .await?
                    .ok_or(Untested::NoEvent(id))?;
                let (run, by_step) = self.about(&e).await?;
                Some((e, run, by_step))
            }
        };
        let held = match f.status() {
            FlowStatus::NeedsApproval => Some(Held::NeedsYes),
            FlowStatus::Paused => Some(Held::Paused),
            _ => None,
        };
        let going = last.filter(|l| l.ended_at.is_none()).map(|l| Going {
            firing: l.id,
            status: l.status,
            overlap: def.overlap,
        });

            let v = verdict(&f, &def, e, run.as_ref(), by.as_deref(), now);

                id: e.id,
                kind: e.kind.clone(),
                summary: e.summary.clone(),

                old: now.duration_since(e.at) > HORIZON,
            }
        });

        let ran = preview::steps(&def, lookup.as_ref().map(|l| l as &dyn Lookup));

            .iter()

            event,
            steps,
        })
    }

/// The next three times `def` fires by itself: from the time planned, when it may fire; else
/// from now, as a yes or a resume plans it.
fn next_times(def: &FlowDef, f: &Flow, held: bool, now: Timestamp) -> Vec<Timestamp> {
    let first = match (held, f.next_at) {
        (false, Some(at)) => Some(at),
        (false, None) => next_fire(def, now, f.last_fired_at),
        (true, _) => next_fire(def, now, None),
    };
    std::iter::successors(first, |t| next_fire(def, *t, Some(*t)).filter(|n| n > t))
        .take(3)
        .collect()
}

/// Why an event does or does not fire the flow, in words.
fn why(v: &Verdict, def: &FlowDef, e: &Event) -> String {
    match v {
        Verdict::Fires => "it fires on it".into(),
        Verdict::NotThisKind if def.trigger.on.is_empty() => "it fires on no event".into(),
        Verdict::NotThisKind => format!("it is on {}, not {}", def.trigger.on.join(", "), e.kind),
        Verdict::Filtered(field) => format!("where.{field} does not match"),
        Verdict::NotApproved => "it needs a yes".into(),
        Verdict::Paused => "it is paused".into(),
        Verdict::Throttled => format!("it fired less than {}s ago (throttle)", def.throttle_secs),
        Verdict::ItsOwnDoing => "the event is the flow's own doing, and a flow never hears itself".into(),
    }
}
```

```rust
    let row = |label: &str, text: String| format!("  {label:<7} {text}");
    let mut v = vec![format!("{name} · {}", when_words(&t.when))];
    match t.held {
        Some(Held::NeedsYes) => v.push(row("held", format!("needs a yes: nothing fires it until rl flow approve {name}"))),
        Some(Held::Paused) => v.push(row("held", format!("paused: only rl flow run {name} fires it"))),
        None => {}
    }
    if !t.next.is_empty() {
        let at: Vec<String> = t.next.iter().map(|x| fmt_when(*x, now)).collect();
        v.push(row("next", at.join(" · ")));
    }
    if let Some(g) = &t.going {
        v.push(row("going", going(g)));
    }
    match &t.event {
        Some(e) => {
            let verdict = if e.fires { "fires it".to_string() } else { format!("not: {}", e.why) };
            let mut s = format!("#{} {} · {} — {verdict}", e.id, e.kind, e.summary);
            if e.old && e.fires {
                s.push_str(" (over 5 minutes old: the loop would pass over it)");
            }
            v.push(row("event", s));
        }
        None if !t.on.is_empty() => v.push(row(
            "on",
            format!(
                "{} · rl flow test {name} --event <id> says whether one fires it (rl events lists them)",
                t.on.join(", ")
            ),
        )),
        None => {}
    }
    let runs: Vec<String> = t.steps.iter().map(|s| runs_words(&s.runs)).collect();
    let w = t.steps.iter().map(|s| s.name.chars().count()).max().unwrap_or(0);
    let rw = runs.iter().map(|r| r.chars().count()).max().unwrap_or(0);
    for (s, r) in t.steps.iter().zip(&runs) {
        let at = match &s.folder {
            Some(p) => format!(" · in {}", display_path(p)),
            None => " · where the event happens".to_string(),
        };
        v.push(format!("  {:<w$}  {r:<rw$}  {}{at}", s.name, s.does));
    }
    v.push(format!("started nothing · rl flow run {name} fires it now"));
    v
}

fn runs_words(r: &Runs) -> String {
    match r {
        Runs::Yes => "runs".into(),
        Runs::If(c) => format!("if {}", c.join(" and ")),
        Runs::No(why) => format!("not: {why}"),
    }
}

        Overlap::Queue => ("a new firing would wait for it", "queue"),
        Overlap::Kill => ("a new firing would stop it first", "kill"),
    };
    format!("{} is still {}: {then} (overlap: {word})", g.firing, g.status)
}
```

```rust
//! A new flow in the panel: what `/flow new …` asks for, and a flow an assistant drafted, shown
//! before anything is written — its `flow.md`, what would stop it loading, and who drafted it.
//! Pure: the words read and a draft checked and said; the panel writes it on `enter`.

use super::theme;
use crate::flow::{NewFile, templates};
use ratatui::text::{Line, Span};
use std::path::Path;

pub const USAGE: &str = "/flow new <name> [words…] · /flow new <name> --from <template> [key=value…]";

/// What `/flow new` asks for.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Asked {
    /// The bare template, in `$EDITOR`.
    Bare { name: String },
    /// A template, its blanks given as `key=value` words.
    From { name: String, template: String, given: Vec<String> },
    /// A draft, from the words.
    Words { name: String, words: String },
}

impl Asked {
    pub fn name(&self) -> &str {
        match self {
            Asked::Bare { name } | Asked::From { name, .. } | Asked::Words { name, .. } => name,
        }
    }
}

/// The words after `/flow new`, read.
pub fn asked(words: &[&str]) -> Result<Asked, String> {
    let Some((name, rest)) = words.split_first() else {
        return Err(USAGE.to_string());
    };
    let name = name.to_string();
    Ok(match rest {
        [] => Asked::Bare { name },
        ["--from"] => return Err(format!("/flow new {name} --from which? {}", templates::names())),
        ["--from", template, given @ ..] => Asked::From {
            name,
            template: template.to_string(),
            given: given.iter().map(|g| g.to_string()).collect(),
        },
        words => Asked::Words {
            name,
            words: words.join(" "),
        },
    })
}

/// A template's files as the panel fills them: its blanks from `key=value` words, `in` the folder
/// `here`; what is missing is said as it would be typed.
pub fn template_files(template: &str, given: &[String], here: &str) -> Result<Vec<NewFile>, String> {
    let t = templates::find(template)?;
    let given = templates::given_in(t, given, here)?;
    let missing = templates::missing(t, &given);
    if !missing.is_empty() {
        return Err(templates::needs(t, &missing, ""));
    }
    templates::fill(t, &given)
}

/// A flow an assistant drafted, not written yet.
pub struct Drafted {
    /// Empty when the draft named none and the person did not either.
    pub name: String,
    pub text: String,
    pub agent: String,
    /// Why it would not load, each at its line; none, and enter may write it.
    pub problems: Vec<String>,
}

impl Drafted {
    /// `text` as `name`'s `flow.md`, checked as a reload checks a flow: `known` says whether a
    /// folder is a project Relay knows; `taken`, why a name may not be a new flow, if it may not.
    pub fn new(
        name: Option<String>,
        text: String,
        agent: String,
        known: &dyn Fn(&Path) -> bool,
        taken: &dyn Fn(&str) -> Option<String>,
    ) -> Self {
        let name = name.unwrap_or_default();
        let mut problems = Vec::new();
        if name.is_empty() {
            problems.push("it names no flow · /flow new <name> <words> names one".to_string());
        } else if let Some(why) = taken(&name) {
            problems.push(why);
        }
        match rl_flow::doc::read(&text) {
            Err(p) => problems.push(at(p.line, &p.message)),
            Ok(doc) => {
                if let Err(found) = rl_flow::def::check(&name, doc, known) {
                    problems.extend(found.iter().map(|p| at(p.line, &p.message)));
                }
            }
        }
        Drafted {
            name,
            text,
            agent,
            problems,
        }
    }

    /// Whether enter may write it.
    pub fn ready(&self) -> bool {
        self.problems.is_empty()
    }

    /// The pane: whose it is and where it would go, what would stop it loading, then `flow.md`.
    pub fn lines(&self) -> Vec<Line<'static>> {
        let name = if self.name.is_empty() { "(unnamed)" } else { self.name.as_str() };
        let mut v = vec![Line::from(vec![
            Span::styled(format!(" {name}"), theme::name()),
            Span::styled(format!("  drafted by {} · flows/{name}/flow.md", self.agent), theme::dim()),
        ])];
        for p in &self.problems {
            v.push(Line::from(Span::styled(format!(" ! {p}"), theme::bad())));
        }
        v.push(Line::raw(""));
        v.extend(self.text.lines().map(|l| Line::raw(format!(" {l}"))));
        v
    }

    /// What the keys do, for the footer.
    pub fn hint(&self) -> String {
        if self.ready() {
            "enter writes it and says yes · e opens it in $EDITOR first · esc lets it go".into()
        } else {
            "it would not load · e opens it in $EDITOR · esc lets it go".into()
        }
    }
}

/// A problem at its line of `flow.md`, when it has one.
fn at(line: Option<usize>, message: &str) -> String {
    match line {
        Some(l) => format!("flow.md:{l} · {message}"),
        None => message.to_string(),
    }
}
```

```rust
    /// once the screen is free (and said yes to on return, as `/flow edit` is); or the words to

    fn new_flow(&mut self, words: &[&str]) {
        let asked = match new_flow::asked(words) {
            Ok(a) => a,
            Err(e) => return self.say(e),
        };
        if let Err(e) = crate::flow::check_name(&self.home, asked.name()) {

    /// lets it go. Checked as a reload would check it, against the projects Relay knows.
    fn show_draft(&mut self, name: Option<String>, text: String, agent: String) {
        let known = self.names.paths();
        let home = self.home.clone();
        let is_known = |p: &Path| {
            let p = form::expand(&p.to_string_lossy());
            known.contains(&std::fs::canonicalize(&p).unwrap_or(p))
        };
        let taken = |n: &str| crate::flow::check_name(&home, n).err().map(|e| format!("{e:#}"));
        let d = new_flow::Drafted::new(name, text, agent, &is_known, &taken);
        self.say(format!(
            "{} drafted {}",
            d.agent,
            if d.name.is_empty() { "a flow" } else { d.name.as_str() }
        ));
        self.mode = Mode::Draft(Box::new(d));
        self.pane = Pane::Facts;
        self.show_pane = true;
    }

    /// The draft written to its folder and said yes to at once, or (`edit`) opened in `$EDITOR`
    /// first and said yes to on return, as a new flow's save is.
    async fn write_draft(&mut self, d: new_flow::Drafted, edit: bool) {

            Err(e) => {
                self.say(format!("{e:#}"));
                self.mode = Mode::Draft(Box::new(d));
            }
        }
    }
```
