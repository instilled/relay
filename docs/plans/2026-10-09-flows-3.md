# Flows, PR 3: seeing it — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A flow is seen where you look: its row says a mark per firing and what the latest came
to, and opens (`→`) to that firing's steps; its pane lists the last firings and the state files,
and walks the steps (`enter` on one joins its run); the catch-up's line says the same, and a
`catch_up: top` flow's latest firing since you left heads the catch-up — the morning brief above
Relay's own bullets; `/summary [deep]` tells one firing; the graph draws a flow's steps, its
trigger at the left.

**Architecture:** What a firing came to is decided once, in `rld` (`flows/outcome.rs`: the last
step that ran and printed something), and sent two ways — its first line on every `Firing` a
client gets (`Firing.outcome`), all of it on asking (`flow.outcome`). `catch_up: top` is a key of
the frontmatter, kept in `FlowDef` and read by the client from the def. The catch-up's heads are
chosen and said in a new `rl-cli/src/catchup/heads.rs`, shared by the panel and `rl since`; the
flow's pane state and its walk are a new pure `tui/firings.rs`; `/summary` of one firing is a new
`SummaryTarget::Firing`, its runs those whose chain is the firing. The graph's steps are nodes
`step:<flow>/<step>` built in `rl-daemon/src/graph.rs` from each flow's def, and drawn by the
node words moved out of `tui/graph.rs` into `tui/graph/words.rs`. `tui/mod.rs` and `tui/rows.rs`
are past 800 lines already: they gain only the wiring, and new panel tests go in a new
`tui/flow_tests.rs`.

**Tech Stack:** Rust 2024 workspace (`Cargo.toml` at the repo root, crates under `code/`), tokio,
rusqlite, serde, ratatui, jiff. Daemon integration tests use `code/rl-daemon/tests/common`
(`Harness`, `Conn`, `approve`, `wait_journal`); panel tests run a real `rld` over a fresh home
(`tui/mod.rs` `tests::panel*`) with what a firing left written into its ledger directly.

**Spec:** `docs/specs/2026-10-07-flows.md` — read "Where you see it" whole, and "The PRs" item 3:
"Seeing it. The graph and the catch-up for flows, `catch_up: top`, `/summary` on a flow and a
firing, the pane." PR 1 (`docs/plans/2026-10-07-flows-1.md`, #151) built the flow row (`f:<name>`,
`rows::FlowRow`, `flows::state_words`, `flows::pane_lines`), the graph's `flow:<name>` and
`ask:<flow>` nodes, `/summary` on a flow (`SummaryTarget::Flow`) and the catch-up's flow line;
PR 2 (`docs/plans/2026-10-08-flows-2.md`, #153) built `runs/<firing>/` and `Facts`. Build on them;
do not rebuild them.

## Review Focus

- **A definition kept before `catch_up` existed.** A firing's `def_json` and an older `rld`'s
  `Flow.def` have no `catch_up` key: they read as no `catch_up`, never as a refusal that stops a
  firing from carrying on after the upgrade. Test: Task 1
  `catch_up_top_is_kept_and_a_def_from_before_it_still_reads`.
- **A firing whose end printed nothing.** prod-logs' probe found nothing (empty out, the rest
  skipped), review was ignored (an ask with no run), or retention dropped the step's journal: the
  outcome is the step before that said something, else none — and the row says `done`, never
  `done · ` with nothing after. Tests: Task 2 `the_last_step_that_ran_and_said_something`, Task 3
  `a_flows_row_says_where_it_stands_and_what_it_came_to`.
- **What heads the catch-up, and what does not.** Yesterday's brief (fired before you left) does
  not head today's catch-up; a brief still running at 07:31 heads it as `running · brief` with
  nothing under it; a source that failed heads it as `failed at gchat` with gchat's error under
  it; a flow without `catch_up: top` stays a line under its project. Test: Task 5
  `a_catch_up_top_flows_latest_firing_since_you_left_heads_it` and
  `a_lead_in_words_is_its_title_then_what_it_printed`.
- **A brief longer than the room.** morning-brief writes 20–40 lines with blank lines between
  people: the head shows at most `heads::LINES` of them, blank lines left out, the last saying
  `… ^o on it shows the rest`; Relay's own top still gets at least two lines; `^o` shows all of
  it, blank lines kept. Test: Task 5 `a_lead_is_cut_where_its_room_ends`.
- **The firings under the caret change.** A refresh while the flow's pane is walked brings fewer
  firings (retention), or the picked one is gone: the caret stays on something that exists and
  the latest is shown again — never an index past the end. Test: Task 6
  `fewer_firings_on_a_refresh_keep_the_caret_in_reach`.

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use jiff::Timestamp;
    use rl_ledger::firings::{self, NewFiring};
    use rl_ledger::{Ledger, runs, session_io};
    use rl_proto::flow::FiringStatus;
    use rl_proto::types::{Run, RunKind};
    use std::collections::BTreeMap;

    /// The outcome of a firing of `steps` — (name, status, what its run printed; None: no run) —
    /// as the ledger has it.
    fn outcome(steps: &[(&str, StepStatus, Option<&str>)]) -> Option<Outcome> {
        let steps: Vec<(String, StepStatus, Option<String>)> = steps
            .iter()
            .map(|(n, s, o)| (n.to_string(), *s, o.map(String::from)))
            .collect();
        let ledger = Ledger::open_in_memory().unwrap();
        ledger
            .call_blocking(move |c| {
                let names: Vec<String> = steps.iter().map(|(n, ..)| n.clone()).collect();
                let at = Timestamp::UNIX_EPOCH;
                firings::insert(
                    c,
                    &NewFiring {
                        id: "f1",
                        flow: "brief",
                        def_json: "{}",
                        hash: "h",
                        trigger: "hand",
                        event: None,
                        at,
                        steps: &names,
                    },
                )?;
                let mut status = BTreeMap::new();
                for (n, s, out) in &steps {
                    status.insert(n.clone(), *s);
                    let Some(out) = out else { continue };
                    let id = format!("run-{n}");
                    runs::insert(c, &Run::new(id.clone(), RunKind::Command, n.clone(), vec![], "/w", "/w", at))?;
                    session_io::append(c, &id, session_io::Direction::Out, out.as_bytes(), at)?;
                    firings::set_step_run(c, "f1", n, &id)?;
                }
                firings::save(c, "f1", &status, FiringStatus::Done, Some(at))?;
                let f = firings::get(c, "f1")?.unwrap();
                Ok(of(c, &f))
            })
            .unwrap()
    }
```

```rust
//! What a firing came to, as a client is sent it: the first line of its last step's out on every
//! firing, all of it on `flow.outcome`.

mod common;
use common::{Conn, Harness, wait_journal};
use rl_core::Home;
use rl_proto::flow::{Firing, Outcome};
use rl_proto::methods::Digest;
use serde_json::json;
use std::path::Path;
use std::time::{Duration, Instant};

/// A daemon on a fresh home with `flow.md` written for `name`; `None` when `rl-session` is not built.
async fn start(tmp: &Path, name: &str, flow_md: &str) -> Option<(Harness, Conn)> {
    let home = Home::at(tmp.join("home"));
    let dir = home.flow_dir(name);
    std::fs::create_dir_all(&dir).unwrap();
    std::fs::write(dir.join("flow.md"), flow_md).unwrap();
    let Some(h) = Harness::on(home) else {
        eprintln!("skipping: rl-session not built (run `cargo test --workspace`)");
        return None;
    };
    let c = Conn::open(&h.home).await;
    Some((h, c))
}

/// Polls `flow.firings` every 50 ms for 10 s until the newest firing of `flow` has ended.
async fn ended(c: &mut Conn, flow: &str) -> Firing {
    let deadline = Instant::now() + Duration::from_secs(10);
    loop {
        let firings: Vec<Firing> = c.ok("flow.firings", json!({ "flow": flow })).await;
        if let Some(f) = firings.into_iter().next().filter(|f| f.ended_at.is_some()) {
            return f;
        }
        assert!(Instant::now() < deadline, "`{flow}` never ended");
        tokio::time::sleep(Duration::from_millis(50)).await;
    }
}

/// `flow.outcome` of `id`: the outcome, or None (a null result).
async fn outcome(c: &mut Conn, id: &str) -> Option<Outcome> {
    let r = c.call("flow.outcome", json!({ "id": id })).await;
    assert!(r.error.is_none(), "{:?}", r.error);
    serde_json::from_value(r.result.unwrap_or_default()).unwrap()
}

#[tokio::test]
async fn a_firing_comes_to_what_its_last_step_printed() {
    let tmp = tempfile::tempdir().unwrap();
    let md = r#"---
steps:
  gather:
    run: echo gathered
  brief:
    after: gather
    run: 'printf "Morning brief\n\nAnna on the parser\n"'
---
"#;
    let Some((h, mut c)) = start(tmp.path(), "brief", md).await else { return };
    common::approve(&mut c, "brief").await;

    let f = ended(&mut c, "brief").await;
    let run = f.steps[1].run.clone().expect("brief ran");
    wait_journal(&h.home, &run, "Anna on the parser").await;

    let f = ended(&mut c, "brief").await;
    assert_eq!(f.outcome.as_deref(), Some("Morning brief"), "{f:?}");
    let d: Digest = c.ok("digest.get", json!({})).await;
    let latest = d.firings.iter().find(|x| x.flow == "brief").expect("the latest firing");
    assert_eq!(latest.outcome.as_deref(), Some("Morning brief"), "on the list too");

    let o = outcome(&mut c, &fired.id).await.expect("an outcome");
    assert_eq!(o.step, "brief");
    assert_eq!(o.text, "Morning brief\n\nAnna on the parser", "all of it, asked for");

}
```

```rust
//! What a firing came to: what its last step to run printed — the brief, the proposal, the
//! error. A flow's row and its catch-up line say the first line of it; a `catch_up: top` flow's
//! head shows all of it. Read from the step's run each time, never kept.

use super::facts::Facts;
use rl_proto::flow::{Firing, Outcome, StepStatus};
use rusqlite::Connection;

/// The most of an outcome's first line a row is sent, in characters.
const LINE_MAX: usize = 200;

/// The last step in the flow's order that ran and printed something — done, or the one that
/// failed — and what it printed. A step skipped, an ask whose option ran nothing, a run whose
/// journal is gone: passed over for the step before. None while nothing has.
pub(crate) fn of(conn: &Connection, f: &Firing) -> Option<Outcome> {
    let facts = Facts::new(conn, f, None);
    f.steps
        .iter()
        .rev()
        .filter(|s| matches!(s.status, StepStatus::Done | StepStatus::Failed) && s.run.is_some())
        .find_map(|s| {
            let text = facts.out(&s.name).filter(|t| !t.is_empty())?;
            Some(Outcome {
                firing: f.id.clone(),
                step: s.name.clone(),
                text,
            })
        })
}

/// The first line of `text` that says something, trimmed and cut to `LINE_MAX` characters.
pub(crate) fn first_line(text: &str) -> String {
    let line = text.lines().map(str::trim).find(|l| !l.is_empty()).unwrap_or_default();
    match line.char_indices().nth(LINE_MAX) {
        Some((i, _)) => format!("{}…", &line[..i]),
        None => line.to_string(),
    }
}

/// `f` as a client is sent it: with the first line of what it came to.
pub(crate) fn told(conn: &Connection, mut f: Firing) -> Firing {
    f.outcome = of(conn, &f).map(|o| first_line(&o.text));
    f
}
```

```rust
    /// One mark per firing — a firing's runs share its id as their chain — oldest first, at
    /// most `n` of the newest: `·` went well, `×` a step failed, `○` one was stopped.
    pub fn marks(&self, n: usize) -> String {
        let worst = |m: char| match m {
            '×' => 2,
            '○' => 1,
            _ => 0,
        };
        let mut firings: Vec<(&str, char)> = Vec::new();
        for i in &self.runs {
            let m = match i.run.state {
                RunState::Failed => '×',
                RunState::Stopped => '○',
                _ => '·',
            };
            match firings.iter_mut().find(|(chain, _)| *chain == i.run.chain) {
                Some((_, was)) if worst(m) > worst(*was) => *was = m,
                Some(_) => {}
                None => firings.push((&i.run.chain, m)),
            }
        }
        firings.iter().take(n).rev().map(|(_, m)| *m).collect()
    }
```

```rust
    tmp: &tempfile::TempDir,
    folder: &Path,
    flow: &str,
    id: &str,
    steps: &[(&str, StepStatus, Option<&str>)],
    status: FiringStatus,

    use rl_ledger::{Ledger, runs, session_io};
    use rl_proto::types::{Cause, Run, RunKind, RunState, Source};

                    id: &id,
                    flow: &flow,
                    def_json: "{}",
                    hash: "h",
                    trigger: "when",
                    event: None,
                    at,
                    steps: &names,
                },
            )?;
            let mut status_of = std::collections::BTreeMap::new();
            for (n, s, out) in &steps {
                status_of.insert(n.clone(), *s);
                let Some(out) = out else { continue };
                let run = format!("{id}-{n}");
                let mut r = Run::new(run.clone(), RunKind::Command, format!("{flow} · {n}"), vec![], &folder, &folder, at);
                r.cause = Cause::Flow {
                    flow: flow.clone(),
                    step: n.clone(),
                };
                r.chain = id.clone();
                runs::insert(c, &r)?;

            firings::save(c, &id, &status_of, status, ended.then_some(at))?;
            Ok(())
        })
        .unwrap();
```

```rust
/// The firings heading a catch-up from `since`, newest first: for each flow that says
/// `catch_up: top`, its latest firing (`firings`: the digest's, each flow's latest) when that
/// started or ended since — one still going too.
pub fn leads<'a>(flows: &'a [Flow], firings: &'a [Firing], since: Timestamp) -> Vec<Lead<'a>> {
    let mut out: Vec<Lead> = flows
        .iter()
        .filter(|f| f.removed_at.is_none() && f.heads_catch_up())
        .filter_map(|f| {
            let firing = firings.iter().find(|x| x.flow == f.name)?;
            let news = firing.started_at >= since || firing.ended_at.is_some_and(|e| e >= since);
            news.then_some(Lead { flow: &f.name, firing })
        })
        .collect();
    out.sort_by(|a, b| {
        b.firing
            .started_at
            .cmp(&a.firing.started_at)
            .then_with(|| a.flow.cmp(b.flow))
    });
    out
}

/// What a firing is, as far as asking again goes: how it stands and the first line it came to.
type Seen = (FiringStatus, Option<String>);

fn seen(f: &Firing) -> Seen {
    (f.status, f.outcome.clone())
}

/// What each lead came to, all of it, by firing: asked for once, and again when the firing has
/// moved on since.
#[derive(Debug, Default)]
pub struct Outcomes(HashMap<String, (Seen, Option<Outcome>)>);

impl Outcomes {
    pub fn put(&mut self, f: &Firing, o: Option<Outcome>) {
        self.0.insert(f.id.clone(), (seen(f), o));
    }

    /// Asks `flow.outcome` of each of `firings` not asked yet, or moved on since; one that fails
    /// is asked again next time.
    pub async fn fetch(&mut self, rpc: &mut Client, firings: Vec<Firing>) {
        for f in firings {
            if self.0.get(&f.id).is_some_and(|(s, _)| *s == seen(&f)) {
                continue;
            }
            if let Ok(o) = rpc.call::<FlowOutcome>(FiringRef { id: f.id.clone() }).await {
                self.put(&f, o);
            }
        }
    }

    pub fn of(&self, firing: &str) -> Option<&Outcome> {
        self.0.get(firing)?.1.as_ref()
    }
}
```

```rust
    }
```

```rust
}

/// `lines` with those whose key is `sel` lit to the width, as the list lights its selection.
pub fn lit(lines: Vec<Line<'static>>, keys: &[String], sel: Option<&str>, w: usize) -> Vec<Line<'static>> {
    lines
        .into_iter()
        .zip(keys)
        .map(|(mut l, k)| {
            if sel == Some(k.as_str()) {
                let short = w.saturating_sub(l.width());
                l.spans.push(Span::raw(" ".repeat(short)));
                l = l.style(theme::selected());
            }
            l
        })
        .collect()
}

/// A lead in the pane: its flow, when it fired and where it stands, all of what it came to —
/// blank lines kept — then what `/summary` said of the firing.
pub fn lead_pane(l: &Lead, outcome: Option<&Outcome>, said: Option<&Summary>, w: usize, now: Timestamp) -> Vec<Line<'static>> {
    let mut lines = vec![
        Line::from(Span::styled(format!(" {}", l.flow), theme::name())),
        Line::styled(
            format!(" flow · fired {} · {}", fmt_when(l.firing.started_at, now), state_words(l.firing)),
            theme::dim(),
        ),
        Line::raw(""),
    ];
    match outcome {
        Some(o) => {
            lines.push(Line::styled(format!(" what {} printed", o.step), theme::dim()));
            for text in o.text.lines() {
                for t in pane::wrap(text, w.saturating_sub(2).max(1)) {
                    lines.push(Line::raw(format!(" {t}")));
                }
            }
        }
        None => lines.push(Line::styled(" nothing printed yet", theme::dim())),
    }
    lines.extend(pane::summary_section(said, w, now));
    lines
}
```

```rust
//! picked — the last few under them, the files the shown one's steps wrote, and a caret that
//! walks the steps and then the firings. `enter` on a step joins its run; on a firing, shows its

pub const LAST: u32 = 8;

/// A flow's pane: its last firings as fetched, which one it shows, where the caret is.
#[derive(Debug, Default, Clone)]
pub struct FlowPane {
    /// The flow these are of.
    pub flow: String,
    /// Its last firings, newest first, as `flow.firings` gave them.
    pub firings: Vec<Firing>,
    /// The firing picked to be shown; none: the latest.
    pub picked: Option<String>,

    pub at: usize,

    pub files: Vec<(String, u64)>,

/// Where the caret can stand.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Stop {
    /// A step of the firing shown, and its run when it has one.
    Step { name: String, run: Option<String> },
    /// One of the last firings, by id.
    Firing(String),
}

/// What a key did to a walk.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Walked {
    /// The caret moved, a firing was shown, or nothing happened: still walking.
    On,
    /// `esc`, or nothing to walk: the walk is over.
    Done,
    /// `enter` on a step with a run: that run, to join.
    Join(String),
    /// `enter` on a step with no run: its name.
    NoRun(String),
}

impl FlowPane {
    /// `flow`'s last firings, newest first. What was picked and the caret stay while it is the
    /// same flow and they still exist; another flow starts afresh.
    pub fn load(&mut self, flow: &str, firings: Vec<Firing>) {
        if self.flow != flow {
            *self = FlowPane {
                flow: flow.to_string(),
                ..Default::default()
            };
        }
        self.firings = firings;
        if self
            .picked
            .as_ref()
            .is_some_and(|id| !self.firings.iter().any(|f| &f.id == id))
        {
            self.picked = None;
        }
        self.at = self.at.min(self.stops().len().saturating_sub(1));
    }

    /// The firing shown: the one picked, else the latest.
    pub fn shown(&self) -> Option<&Firing> {
        match &self.picked {
            Some(id) => self.firings.iter().find(|f| &f.id == id),
            None => self.firings.first(),
        }
    }

    /// The firing picked, when it is not the latest: what `/summary` on the flow's row tells.
    pub fn picked_firing(&self) -> Option<&Firing> {
        self.picked.as_ref().and(self.shown())
    }

    fn steps_len(&self) -> usize {
        self.shown().map_or(0, |f| f.steps.len())
    }

    /// Where the caret can stand: the shown firing's steps, then each of the last firings.
    pub fn stops(&self) -> Vec<Stop> {
        let steps = self.shown().into_iter().flat_map(|f| &f.steps).map(|s| Stop::Step {
            name: s.name.clone(),
            run: s.run.clone(),
        });
        steps
            .chain(self.firings.iter().map(|f| Stop::Firing(f.id.clone())))
            .collect()
    }

    /// The step the caret is on, by its place among the shown firing's steps.
    pub fn step_at(&self) -> Option<usize> {
        (self.at < self.steps_len()).then_some(self.at)
    }

    /// A key while the pane is walked.
    pub fn key(&mut self, code: KeyCode) -> Walked {
        let stops = self.stops();
        let last = stops.len().saturating_sub(1);
        match code {
            KeyCode::Up => {
                self.at = self.at.saturating_sub(1);
                Walked::On
            }
            KeyCode::Down => {
                self.at = (self.at + 1).min(last);
                Walked::On
            }
            KeyCode::Esc => Walked::Done,
            KeyCode::Enter => match stops.get(self.at) {
                Some(Stop::Step { run: Some(r), .. }) => Walked::Join(r.clone()),
                Some(Stop::Step { name, run: None }) => Walked::NoRun(name.clone()),
                Some(Stop::Firing(id)) => {
                    let latest = self.firings.first().map(|f| &f.id) == Some(id);
                    self.picked = (!latest).then(|| id.clone());
                    self.at = 0;
                    Walked::On
                }
                None => Walked::Done,
            },
            _ => Walked::On,
        }
    }

    /// The last firings, newest first, a line each — when, where it stands, what it came to —
    /// the one shown marked `▸`, and while walking the caret's lit.
    pub fn firing_lines(&self, walking: bool, w: usize, now: Timestamp) -> Vec<Line<'static>> {
        let steps = self.steps_len();
        let shown = self.shown().map(|f| f.id.clone());
        let mut lines = vec![Line::raw(""), Line::from(Span::raw(" firings").dim())];
        for (n, f) in self.firings.iter().enumerate() {
            let lit = walking && self.at == steps + n;
            let caret = match (lit, shown.as_deref() == Some(f.id.as_str())) {
                (true, _) => "❯",
                (false, true) => "▸",
                _ => " ",
            };
            let row = format!(
                " {caret} {:<12} {:<18} {}",
                fmt_when(f.started_at, now),
                state_words(f),
                f.outcome.as_deref().unwrap_or("")
            );
            let line = Line::raw(fit(&row, w).trim_end().to_string());
            lines.push(if lit { line.style(theme::selected()) } else { line });
        }
        lines
    }
}

/// The files a firing's folder holds — what its steps wrote to `$RELAY_WORK` — by name, with
/// their sizes; Relay's own `.relay/`, anything hidden and any folder left out. None when the
/// folder is not there.
pub fn files_in(dir: &Path) -> Vec<(String, u64)> {
    let Ok(entries) = std::fs::read_dir(dir) else {
        return vec![];
    };
    let mut out: Vec<(String, u64)> = entries
        .flatten()
        .filter_map(|e| {
            let name = e.file_name().to_string_lossy().into_owned();
            let meta = e.metadata().ok()?;
            (!name.starts_with('.') && meta.is_file()).then_some((name, meta.len()))
        })
        .collect();
    out.sort();
    out
}

/// `note.txt 12 B · report.md 2 kB`.
pub fn files_words(files: &[(String, u64)]) -> String {
    files
        .iter()
        .map(|(name, len)| format!("{name} {}", size(*len)))
        .collect::<Vec<_>>()
        .join(" · ")
}

fn size(n: u64) -> String {
    match n {
        n if n >= 1 << 20 => format!("{:.1} MB", n as f64 / (1u64 << 20) as f64),
        n if n >= 1 << 10 => format!("{} kB", n >> 10),
        n => format!("{n} B"),
    }
}
```

```rust
    // Each flow as loaded: its folder, its def, and what its `on` takes.
    let flows: Vec<(&Flow, Option<PathBuf>, Option<FlowDef>, Vec<String>)> = inp
        .flows
        .iter()
        .filter(|f| f.removed_at.is_none())
        .map(|f| {
            let def = serde_json::from_value::<FlowDef>(f.def.clone()).ok();
            let on = def.as_ref().map(|d| d.trigger.on.clone()).unwrap_or_default();
            (f, f.folder.clone(), def, on)
        })
        .collect();
    let mut g = Builder::default();

    for (f, folder, def, _) in &flows {
        g.node(Node {
            status: Some(f.status()),
            detail: f.when(),
            next_at: f.next_at,
            flow: Some(f.name.clone()),
            ..bare(&flow_id(&f.name), NodeKind::Flow, &f.name, folder.clone())
        });
        // Its steps, wired as it writes them: from the flow itself when a step waits on
        // nothing, else from each step it comes after; its `if:` on the edge.
        for s in def.iter().flat_map(|d| &d.steps) {
            let id = step_id(&f.name, &s.name);
            let (kind, detail) = match &s.does {
                Does::Ask(a) => (NodeKind::Ask, a.text.clone()),
                Does::Run(a) => match &a.run {
                    Some(Task::Agent { .. }) => (NodeKind::Agent, a.label()),
                    _ => (NodeKind::Shell, a.label()),
                },
            };
            g.node(Node {
                status: Some(f.status()),
                detail,
                flow: Some(f.name.clone()),
                ..bare(&id, kind, &s.name, folder.clone())
            });
            let label = s.if_.as_ref().map(|c| format!("if {c}")).unwrap_or_default();
            if s.after.is_empty() {
                g.edge(&flow_id(&f.name), &id, &label, true);
            }
            for a in &s.after {
                g.edge(&step_id(&f.name, a), &id, &label, true);
            }
        }
    }

    // Questions its ask steps put to you, on the step that asked: who is waiting, and the
    // newest naming it. A step the flow no longer has still shows while it asks.
    for a in inp.asks {
        let flow = flow_id(&a.flow);
        let Some(owner) = g.nodes.get(&flow) else { continue };
        let (folder, status) = (owner.folder.clone(), owner.status);
        let id = step_id(&a.flow, &a.step);
        if !g.has(&id) {
            g.node(Node {
                status,
                flow: Some(a.flow.clone()),
                ..bare(&id, NodeKind::Ask, &a.step, folder)
            });
            g.edge(&flow, &id, "", true);
        }
        let node = g.nodes.get_mut(&id).unwrap();
        node.detail = a.title.clone();
        if a.status == DecisionStatus::Open {
            node.waiting.push(a.id.clone());
        }
        g.did(&id);
    }

    // Runs: each onto the node that stands for it; a step's on its flow's too.
    for run in inp.runs {

        g.ensure(&id, run.kind, &run.workspace);
        g.tally(&id, run);
        if id.starts_with("step:")
            && let Some(flow) = g.nodes[&id].flow.clone()

            g.tally(&flow_id(&flow), run);
        }
        // An ask's option runs as the step's own: the question already counted it.
        if g.nodes[&id].kind != NodeKind::Ask {
            g.did(&id);
        }
    }

    // Events: from whoever raised them to every flow that hears them.
    let mut heard: BTreeMap<String, BTreeSet<String>> = BTreeMap::new();
    for e in inp.events {
        let from = match (&e.run, &e.by_flow) {
            (Some((cause, kind, ws)), _) => g.producer(cause, *kind, ws),
            (None, Some(name)) if e.kind.starts_with("decision.") => {
                match e.by_step.as_deref().map(|s| step_id(name, s)).filter(|id| g.has(id)) {
                    Some(id) => id,
                    None if g.has(&flow_id(name)) => flow_id(name),
                    None => outside(&e.workspace),
                }
            }
            (None, Some(name)) if g.has(&flow_id(name)) => flow_id(name),
            (None, _) => outside(&e.workspace),
        };
        for (f, _, _, on) in &flows {

                continue;

                Some((_, kind, ws)) => g.ensure(&from, *kind, ws),
                None => g.ensure_outside(&from, &e.workspace),
            }
            g.count(&from, &to, &e.kind, e.count);
            heard.entry(to).or_default().insert(e.kind.clone());
        }
    }

    // A way in for every pattern nothing raised.
    for (f, _, _, on) in &flows {
        // … as before, with `on` from the tuple …
    }

    g.finish(since)
}
```

```rust
/// What starts a flow, as its box says it — each part of `when()` on its own: `◷ every 30m`,
/// `◷ at 07:30, Mon–Fri`, `◆ run.failed`, `by hand`.
pub fn trigger_words(when: &str) -> String {
    if when.is_empty() {
        return String::new();
    }
    when.split(" or ")
        .map(|part| match part.strip_prefix("on ") {
            Some(kinds) => format!("◆ {kinds}"),
            None if part == "by hand" => part.to_string(),
            None => format!("◷ {}", crate::tui::flows::when_words(part)),
        })
        .collect::<Vec<_>>()
        .join(" · ")
}
```
